# Архітектура проєкту

## Загальний опис
Проєкт **infoklas-app** побудований за модульною архітектурою з чітким розділенням відповідальності між компонентами системи.

## Основні компоненти
* **Frontend:** Клієнтська частина додатка (інтерфейс користувача).
* **Backend:** Серверна частина, яка забезпечує бізнес-логіку та обробку запитів через API.
* **Database:** База даних для надійного збереження інформації проєкту.

## Конфігурація
Налаштування середовища зчитуються з файлу `.env`, який створюється локально на основі шаблону `.env.example`.
